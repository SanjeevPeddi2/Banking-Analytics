# 🏦 Banking Analytics

## 📌 Project Overview

Banking Analytics is a data analytics project developed to analyze banking loan performance and banking transactions using Excel, MySQL, Power BI and Tableau.

This project consists of two interactive dashboard solutions :

1. Banking Loan Analysis & Dashboard
2. Debit and Credit Banking Transactions Dashboard

The objective is to transform raw banking data into meaningful insights through data analysis, SQL queries, KPI calculations and interactive visualizations.

## 🛠️ Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI
- Tableau

## 📊 Dashboard 1: Banking Loan Analysis

### Project Description

Analyzed banking loan data to understand loan distribution, repayment performance, customer lending patterns and default risk.

### Key Performance Indicators

- Total Loan Accounts
- Total Loan Amount
- Total Funded Amount
- Average Loan Amount
- Default Rate
- Delinquency Rate
- Total Repayments Received
- Average Interest Rate

### Analysis Performed

- Loan Status Analysis
- Loan Purpose Analysis
- Product-Wise Loan Analysis
- Branch-Wise Loan Performance
- Repayment Analysis
- Default Risk Analysis

### Technologies Used

Excel, MySQL, Power BI and Tableau.

## 💳 Dashboard 2: Debit and Credit Banking Transactions

### Project Description

Analyzed 100,000 banking transaction records to understand customer transaction activities, debit and credit performance, bank-wise performance and monthly transaction trends.

### Key Performance Indicators

- Total Transactions
- Unique Customers
- Total Transaction Value
- Average Transaction Value
- Total Credit Amount
- Total Debit Amount
- Net Credit-Debit Difference
- Transaction Percentage

### Analysis Performed

- Credit vs Debit Analysis
- Bank-Wise Transaction Analysis
- Branch-Wise Performance
- Transaction Method Analysis
- Monthly Transaction Trends
- Customer Transaction Analysis

### Technologies Used

Excel, MySQL, Power BI and Tableau.
